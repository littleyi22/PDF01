# PDF萬用工具 v3.1 (奕鈞老師製作)

一個純前端、客戶端執行的瀏覽器 PDF 處理系統，提供深藍科技風格的美觀介面，支援使用者上傳多份 PDF 檔案進行即時預覽、裁切、選頁與下載。為教師行政減負與教學備課量身打造，100% 確保資料隱私與安全。

🔗 **線上使用**：[https://littleyi22.github.io/PDF01/](https://littleyi22.github.io/PDF01/)

## 🌟 核心功能特色
- 📄 **無限制 PDF 預覽與整併**：支援多份 PDF 上傳，將所有頁面預覽呈現，自由拖曳調整頁面順序，或指定移動到特定頁數之後。
- 🔍 **放大檢視與縮圖控制**：提供高清晰的燈箱縮放預覽，並可自由滑動調整縮圖版面大小。
- 🔄 **頁面旋轉與多選控制**：支援單頁/多頁的自由旋轉與一鍵全選操作。
- 📦 **單頁拆分打包**：將 PDF 拆分，並可自動打包匯出全新的 PDF 或高畫質 PNG 圖片檔（以 ZIP 壓縮）。
- 📉 **自訂畫質壓縮**：支援高解析度重繪並轉檔，大幅減小 PDF 檔案體積，節省上傳雲端時間。
- 🛡️ **浮水印與自動頁碼**：重要文件可一鍵加上客製化浮水印，或自動加上指定位置與大小的頁碼。
- 🖨️ **高畫質灰階轉換**：一鍵將彩色的 PDF 轉換為高畫質黑白圖片版 PDF，列印考卷講義省墨最實用。
- 🔒 **100% 本地端安全隱私**：所有的處理與運算皆在使用者電腦的瀏覽器中完成，完全無需上傳雲端。

## 🛠️ 使用技術
- HTML5 / Vanilla CSS / Vanilla JavaScript
- [PDF.js](https://mozilla.github.io/pdf.js/)：用於精準解析與圖層呈現 PDF 引擎。
- [PDF-Lib](https://pdf-lib.js.org/)：用於重組、建立、合併與輸出實體 PDF 結構檔。
- [JSZip](https://stuk.github.io/jszip/)：處理圖檔封裝。
- [SortableJS](https://sortablejs.github.io/Sortable/)：提供直覺的拖曳重排。
- [Phosphor Icons](https://phosphoricons.com/)：高質感向量圖標庫。
